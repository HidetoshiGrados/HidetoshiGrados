## 🚀 Qué he construido

> La mayor parte de mi trabajo es para clientes y vive en repositorios privados de la empresa. Aquí lo describo sin datos confidenciales.

- **Pipeline de datos financiero de punta a punta.** Desde el ERP contable hasta un dashboard ejecutivo que se actualiza solo cada día, sin intervención manual. Python para la extracción, SQL en BigQuery para la limpieza y el modelo dimensional, y Docker + Cloud Run + Cloud Scheduler para orquestar, con alertas y una bitácora de decisiones.
- **CFO Virtual (Perú Business Fest 2026).** Tablero financiero conversacional: el usuario pregunta por voz o texto y el tablero responde con la conclusión, las cifras y el gráfico, todo calculado sobre la base de datos. Las respuestas se validaron contra SQL independiente.
- **Plataforma de agentes y automatizaciones para pymes.** Integra dashboards financieros, automatizaciones y agentes de IA con gobierno de datos.
- **Automatizaciones de procesos financieros.** Digitalización de facturas, monitoreo de calidad de datos, flujo de caja y proyección de ventas.
